# Capri на Nobara Linux

Это Linux-режим фан-проекта Capricorn. Он использует исходный анимированный аватар, офлайн-распознавание русского языка Vosk, локальную модель Ollama и офлайн-озвучивание через Piper. Голос можно сменить через меню значка Капри → «Голос Капри».

## Установка в Nobara/KDE

1. Убедиться, что в системе есть `pw-record` (PipeWire; обычно уже установлен в Nobara KDE) и `espeak-ng`:

   ```bash
   sudo dnf install espeak-ng
   ```

   Для регулировки громкости голосом нужен `wpctl` (обычно установлен вместе с PipeWire/WirePlumber). Для управления музыкой можно установить `playerctl`.

2. В каталоге проекта выполнить:

   ```bash
   bash setup-linux.sh
   bash run-linux.sh
   ```

   Чтобы добавить Капри в меню приложений KDE, выполни `bash install-linux.sh`.

3. В Ollama должна быть локальная модель. По умолчанию используется `qwen3.5:9b`; модель можно поменять в `~/.config/capricorn/config.json`.

## Пакеты для Linux

Workflow проекта собирает релиз для 64-разрядных систем x86_64 в трёх форматах: `.deb` для Debian/Ubuntu и производных, `.rpm` для Fedora/Nobara и AppImage для других дистрибутивов. Пакеты содержат приложение и офлайн-модель распознавания Vosk; при первом запуске Vosk распакуется в `~/.local/share/capricorn`. Для озвучивания в пакетах используется системный `espeak-ng`.

Для работы голосового ввода требуется PipeWire (`pw-record`) либо ALSA (`arecord`). Ответы локальной модели требуют установленной Ollama и загруженной в неё модели. Эти системные компоненты не входят в пакет Capri. AppImage рассчитан на x86_64; совместимость зависит от библиотек конкретного дистрибутива.

Пакеты прикладываются к GitHub Release при публикации тега вида `v0.2.0`. Сборку также можно запустить вручную во вкладке **Actions → Linux packages → Run workflow**.

## Голосовые команды

Сначала скажи «Капри», затем вопрос или команду. Если микрофон/распознавание не запустились, Капри остаётся доступна через значок в системном трее и по клику на аватар.

Локальная модель и Vosk обрабатывают запросы на ПК. Голос синтезируется локально через Piper. Последние диалоги и заметки по команде «запомни…» хранятся локально в `~/.local/state/capricorn/memory.json`; посмотреть и стереть их можно через меню «Память Capri». Режим сложных вопросов включается в меню значка Capri и автоматически срабатывает для просьб вроде «подумай пошагово» и «проанализируй».

Команды рабочего стола ограничены безопасным набором: открыть известный сайт/приложение, поиск в браузере, время/дата, громкость и управление плеером. Создание папки и удаление отдельного файла требуют явного подтверждения в диалоге; удаление ограничено файлами в домашней папке и не удаляет каталоги. Выключение компьютера, очистка корзины и прочие системные команды не подключены.

## Ограничения текущего Linux-режима

Upstream-версия ориентирована на Windows. Этот режим сохраняет её аватар и персонажа, но не переносит пока Windows-специфичные функции: ввод текста в чужие окна, управление чатами Telegram, яркость экрана, диагностику Windows и сложное управление окнами. На Wayland KDE перемещение и закрепление прозрачного окна могут зависеть от композитора; если аватар позиционируется неверно, попробуй войти в сессию X11.

### Проверка отрисовки пакета

Сборка использует Python 3.12 и PySide6 6.11.1. После упаковки workflow запускает `QT_QPA_PLATFORM=offscreen dist/capricorn/capricorn --check-render`: 1200 кадров аватара без микрофона и запросов к Ollama. Это проверяет запуск Qt и отрисовку, но не заменяет проверку звука и рабочего стола на целевой системе.
